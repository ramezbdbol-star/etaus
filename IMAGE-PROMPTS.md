# Photo prompts for the OEM Sourcing Ltd website

Generate each image in ChatGPT (or any image generator), then save it into `img/` with the file name shown.
Any size and format works. Landscape 3:2 for the wide images, portrait 2:3 for the hero.
The page crops each photo to fit, so keep the main subject near the centre.

Add this to the end of every prompt:

> Photorealistic documentary photograph, natural light, shot on a 35mm lens, realistic skin, fabric and material textures. No text, no logos, no watermarks, no readable signs. Not an illustration, not CGI.
